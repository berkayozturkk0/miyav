# Miyav Agent 🐱

Masaüstünde gezen, ekranına bakıp yorum yapan, "miyav" deyince seni dinleyen yapay zekalı kedi.

## İndir

**[KediMasaustu.exe'yi indir](https://github.com/berkayozturkk0/miyav/raw/main/KediMasaustu.exe)** (Windows)

## Kurulum

1. `KediMasaustu.exe`'yi indir, çift tıkla. Windows uyarı verirse **Ek bilgi > Yine de çalıştır** de.
2. Kedi ücretsiz bir **Gemini anahtarı** ister: [aistudio.google.com/apikey](https://aistudio.google.com/apikey) adresinden **Create API key** de, kopyala, kedinin penceresine yapıştır.
3. Bitti. Kediye tıklayıp sohbet et, sağ tık menüsünde oyunlar ve ayarlar var. "Miyav" ile konuşmak için: sağ tık > **Mikrofonla konuşma**.

Kapatmak için: kediye sağ tık > **Kapat**.

## Gizlilik

Kedi yorum yapmak için ekran görüntüsünü Google Gemini'ye gönderir. Gizli bir şey açıkken sağ tık > **Otomatik yorum**'u kapat. "Miyav" bekleme bilgisayarında olur, ses kaydedilmez. Oyundayken hiçbir şey gönderilmez. Anahtarın sadece bilgisayarında saklanır.
